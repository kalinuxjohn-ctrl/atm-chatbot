Administration du Copilote

Examinez les solutions proposées par les techniciens et gérez les réponses enregistrées que le Copilote donne sans IA : codes d’erreur connus et pannes fréquentes.

Une proposition approuvée rejoint le catalogue d’actions du Copilote. Une proposition rejetée reste dans l’historique.

Saisissez la clé administrateur pour afficher les propositions.

Un code apparaît dans le menu « Codes d’erreur connus » du Copilote s’il a un équipement et une réponse. Sans réponse, il reste trouvable par la recherche de codes.

Saisissez la clé administrateur pour afficher les codes d’erreur.

Chaque panne apparaît dans le menu « Pannes fréquentes » de son équipement, dans l’ordre indiqué. Le Copilote répond avec le texte enregistré, sans IA.

Saisissez la clé administrateur pour afficher les pannes fréquentes.
