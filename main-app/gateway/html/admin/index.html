Actions et résultats

Codes d'erreur

Un code apparaît dans le menu « Codes d'erreur connus » de l’ATM-Chatbot s'il a un équipement et une réponse. Sans réponse, il reste trouvable par la recherche.

Chaque ajout reçoit un ID entier et crée son fichier dans db/code_erreurs avant l'enregistrement en base. Les modifications et suppressions sont synchronisées avec ce JSON.

Pannes fréquentes

Chaque panne apparaît dans le menu « Pannes fréquentes » de son équipement, dans l'ordre indiqué. L’ATM-Chatbot répond avec le texte enregistré, sans IA.
