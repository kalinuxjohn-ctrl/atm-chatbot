Propositions de solution

Solutions trouvées sur le terrain et proposées depuis le Copilote. Approuvée, une proposition rejoint le catalogue d'actions ; rejetée, elle reste dans l'historique.

Ajouts d'intervention

Interventions racontées par les techniciens depuis le Copilote. Approuvée, une demande est écrite dans l'historique et nourrit les statistiques des solutions.

Codes d'erreur

Un code apparaît dans le menu « Codes d'erreur connus » du Copilote s'il a un équipement et une réponse. Sans réponse, il reste trouvable par la recherche.

Pannes fréquentes

Chaque panne apparaît dans le menu « Pannes fréquentes » de son équipement, dans l'ordre indiqué. Le Copilote répond avec le texte enregistré, sans IA.
